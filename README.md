# Arcane Labs Pixelate Website

https://artefakt.mov/

saya ingin buat seperti itu, lalu text artefact diganti jadi Arcane Labs, lengkap dengan animasi semuanya di website tersebut, namun rebranding jadi Arcane Labs.

Fokus ke bagian animasi dan logo header yang bertuliskan " Artefact " karena ketika cursor di arahkan ke text tersebut seperti ada effect chaos terhadap tulisan tersebut. background dan effect animasinya saya ingin serupa dan sama seperti website terseut lengkap dengan posisi posisi nya.
